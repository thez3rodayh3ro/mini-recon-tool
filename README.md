# 🔍 Mini Recon Tool (Python)

A lightweight Python-based reconnaissance tool designed to scan open ports on a target system and identify common services. This project demonstrates foundational networking and cybersecurity concepts used in real-world penetration testing and red team workflows.

## 🚀 Features

* Scan custom port ranges
* Detect open and closed ports
* Identify common services (HTTP, SSH, FTP, etc.)
* Save scan results to a file
* Display scan summary with timing

## 🧠 Skills Demonstrated

* Python scripting
* Networking with sockets
* Input handling & validation
* File handling and reporting
* Basic security tool development

## ⚙️ How to Run

```bash
python mini-recon-tool.py
```

## 📌 Example Output

```
OPEN: 22 (SSH)
OPEN: 80 (HTTP)

--- SUMMARY ---
Total Open Ports: 2
Scan Time: 1.23 seconds
```
